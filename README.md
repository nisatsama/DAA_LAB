# Design and Analysis of Algorithms (DAA) Lab

## 📚 Overview

This repository contains the laboratory programs implemented as part of the **Design and Analysis of Algorithms (DAA)** course during the B.Tech Computer Science & Engineering curriculum.

The programs are written in **C** and demonstrate fundamental algorithmic techniques, problem-solving approaches, and complexity analysis.

---

## 🎯 Course Objectives

* Understand the principles of algorithm design.
* Analyze time and space complexity of algorithms.
* Apply various algorithmic paradigms to solve computational problems.
* Develop efficient solutions for real-world problems.

---

## 🛠️ Language Used

* C Programming Language

---

## 📂 Topics Covered

### Unit 1: Introduction to Algorithms

* Time Complexity Analysis
* Asymptotic Notations

  * Big O (O)
  * Omega (Ω)
  * Theta (Θ)

### Unit 2: Divide and Conquer

* Binary Search
* Merge Sort
* Quick Sort

### Unit 3: Dynamic Programming

* Fibonacci Series using Dynamic Programming
* 0/1 Knapsack Problem
* Matrix Chain Multiplication (MCM)
* Assembly Line Scheduling

### Unit 4: Greedy Algorithms

* Fractional Knapsack Problem
* Activity Selection Problem

### Unit 5: Graph Algorithms

* Breadth First Search (BFS)
* Depth First Search (DFS)
